ACT IV // ARCHITECTURAL CLIMAX · THE 3 SESSION BREAKTHROUGHS & END-TO-END LOOP

Synthesis: Zero-CORS Dual-Layer Cockpit Architecture

Distilled from 105 ideas across TRIZ, Morphological Analysis, and Cross-Pollination, three structural breakthroughs resolve every contradiction simultaneously.

Breakthrough #1 · Transport & Git Hygiene

Zero-CORS, Zero-Git-Noise Transport

Commit a single static .aidd/cockpit.html once and have sync-state.sh/.ps1 generate a gitignored .aidd/views/aidd-data.js loaded via <script src='views/aidd-data.js'> — <script src> bypasses file:/// CORS in Chrome, Safari, Firefox & Edge while producing zero HTML Git diffs or merge conflicts.

Breakthrough #2 · Token & Cognitive Economy

Zero-LLM-HTML Token Rule

LLMs never waste tokens or risk broken markup generating HTML for Briefs, Specs, or Stories; LLMs write 100% pure Markdown, and cockpit.html turns Markdown conventions (YAML frontmatter, Context Capsules, AC checkboxes, Allowed Paths, Execution Evidence) into interactive diagrams, progress rings, X-ray traceability, and Dark-Cockpit anomaly alerts.

Breakthrough #3 · Bi-Directional Loop Closure

Browser as Prompt Compiler

Every human review interaction in cockpit.html (hover clause comments, Scope toggles, Open-Question answers, Blind Second-Opinion checks, Two-Hat Verdict switches) compiles into a surgical @aidd-review-patch clipboard prompt for any agent — with optional direct disk write-back via FileSystemFileHandle.createWritable().
