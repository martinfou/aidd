Axis 02 // Quality Verification ADVERSARIAL GATE
Idea by Coach MA-03

Adversarial Two-Hat Gate

Builder cannot mark a story Done; a separate Reviewer/QA skill must run tests and verify AC against git diff.

Idea by User MA-04

3-Layer Quality Gate Architecture

Combines role separation, recorded terminal proof, and deterministic pre-commit enforcement.

Layer 01
Two-Hat Builder / Reviewer Split Builder implements; independent Reviewer/QA skill verifies AC vs git diff.
Layer 02
Evidence-First Terminal Output Actual test & command output captured directly inside the story packet.
Layer 03
bash / powershell Pre-Commit Guard Deterministic local shell check before code is committed.
