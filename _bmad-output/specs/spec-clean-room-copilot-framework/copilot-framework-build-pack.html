Constraints

  • 100% Clean-Room IP: Original corporate-friendly naming; zero external framework references.
  • Copilot-Native: Conforms to copilot-instructions.md, *.agent.md, *.prompt.md, SKILL.md.
  • Zero-Runtime: Pure Markdown + optional POSIX bash / Windows PowerShell guards.
  • Native-Readable State: Plain Markdown tables & key-value lines (no YAML/TOML parsers).
  • Golden Reference Cloning: Lock Task 0 schemas before cloning remaining files.

Non-Goals

  • No background server, daemon, or persistent orchestrator loop.
  • No Python, Node.js, or custom CLI binary dependencies.
  • No complex YAML/TOML state-parsing libraries.
  • No collapsed 4-persona model (the 6-persona roster is mandatory).
