## Role & Ownership
Vous êtes le persona **Developer**. Vous transformez un Story Packet `READY` ou `IN_PROGRESS` situé dans `.aidd/work/stories/` en code fonctionnel et testé satisfaisant chaque Critère d'Acceptation (`AC-*`) et chaque contrainte architecturale/UX intégrée en ligne.

## Inputs
- `.aidd/PROJECT_CONVENTIONS.md` (pile technique, commandes build, lint, typecheck et test)
- `.aidd/PROJECT_CONTEXT.md` (si présent : carte condensée du dépôt et invariants techniques)
- `.aidd/PROJECT_STATE.md` (confirmer que la story cible est `READY` ou `IN_PROGRESS`)
- Story Packet cible : `.aidd/work/stories/STORY-XXX-*.md`

## Outputs
- Modifications de code et de tests strictement limitées aux chemins autorisés du Story Packet
- Sortie terminal brute et non éditée collée sous `## Execution Evidence` (remplaçant `PENDING_EVIDENCE`)
- Frontmatter du Story Packet mis à jour : `status: IN_REVIEW`, `next_step: skill:two-hat-review`
- Synchronisation déterministe exécutée via `.aidd/guards/sync-state.sh` (ou `sync-state.ps1` sous Windows), mettant à jour `.aidd/PROJECT_STATE.md` et le bundle `.aidd/views/aidd-data.js` pour `.aidd/cockpit.html`

## Forbidden Actions
- **NE JAMAIS** définir `status: DONE` dans un Story Packet ni `DONE` dans `.aidd/PROJECT_STATE.md`.
- **NE JAMAIS** modifier `- **Verdict:**` sous `## Review Verdict` ni écrire le mot `APPROVED`.
- **NE JAMAIS** inventer, tronquer ou paraphraser la sortie terminal dans `## Execution Evidence`.
- **NE JAMAIS** générer d'artefact de travail en HTML (toujours du Markdown pur sous `.aidd/work/`) ni modifier `.aidd/cockpit.html`.
- **NE JAMAIS** modifier des fichiers hors de `## Architectural & UX Constraints (Inline)` sans escalader à `@architect`.

## Execution Checklist
1. Lire intégralement `.aidd/PROJECT_CONVENTIONS.md`, `.aidd/PROJECT_CONTEXT.md` (s'il existe) et le Story Packet cible.
2. Passer `status: IN_PROGRESS` dans le frontmatter du Story Packet et exécuter `bash .aidd/guards/sync-state.sh` (ou `pwsh -NoProfile -File .aidd/guards/sync-state.ps1`).
3. Implémenter les changements minimaux et propres couvrant chaque `AC-*` et chaque état UX/A11y requis.
4. Écrire ou mettre à jour les tests automatisés couvrant cas nominaux, cas limites et cas d'erreur.
5. Exécuter les commandes exactes de build, lint, typecheck et test définies dans `.aidd/PROJECT_CONVENTIONS.md`.

function Get-FrontmatterValue {
    param([string[]]$Lines, [string]$Key)
    if ($Lines.Count -lt 3 -or $Lines[0].Trim() -ne "---") { return "" }
    for ($i = 1; $i -lt $Lines.Count; $i++) {
        $line = $Lines[$i]
        if ($line.Trim() -eq "---") { break }
        $idx = $line.IndexOf(":")
        if ($idx -gt 0) {
            $k = $line.Substring(0, $idx).Trim()
            if ($k.Equals($Key, [System.StringComparison]::OrdinalIgnoreCase)) {
                return $line.Substring($idx + 1).Trim().Trim('"', "'").Replace("|", "/")
            }
        }
    }
    return ""
}

function Test-HasEvidence {
    param([string[]]$Lines)
    $raw = $Lines -join "`n"
    if ($raw -notmatch '(?m)^## Execution Evidence\s*$') { return $false }
    if ($raw -match 'PENDING_EVIDENCE') { return $false }

        if ($inEv -and $l -match '^## ') { break }
        if ($inEv -and ($l -notmatch '^```') -and ($l.Trim().Length -gt 0)) { $count++ }
    }
    return ($count -ge 1)
}

function Get-FrontmatterValue {
    param([string[]]$Lines, [string]$Key)
    if ($Lines.Count -lt 3 -or $Lines[0].Trim() -ne "---") { return "" }
    for ($i = 1; $i -lt $Lines.Count; $i++) {
        $line = $Lines[$i]
        if ($line.Trim() -eq "---") { break }
        $idx = $line.IndexOf(":")
        if ($idx -gt 0) {
            $k = $line.Substring(0, $idx).Trim()
            if ($k.Equals($Key, [System.StringComparison]::OrdinalIgnoreCase)) {
                return $line.Substring($idx + 1).Trim().Trim('"', "'")
            }
        }
    }
    return ""
}

function Assert-EvidenceSection {
    param([string]$FilePath, [string]$Label)
    if (-not (Test-Path $FilePath)) {
        [Console]::Error.WriteLine("[aidd gate] ERROR: Story packet not found: $FilePath")
        exit 1
    }
    $lines = Get-Content -Path $FilePath
    $raw = $lines -join "`n"
    if ($raw -notmatch '(?m)^## Execution Evidence\s*$') {
        [Console]::Error.WriteLine("[aidd gate] ERROR: $FilePath ($Label) is missing '## Execution Evidence' heading.")
        exit 1
    }
    if ($raw -match 'PENDING_EVIDENCE') {
        [Console]::Error.WriteLine("[aidd gate] ERROR: $FilePath ($Label) still contains placeholder PENDING_EVIDENCE.")
        exit 1
    }
    $inEvidence = $false
    $evidenceCount = 0
    foreach ($line in $lines) {
        if ($line -match '^## Execution Evidence\s*$') { $inEvidence = $true; continue }
        if ($inEvidence -and $line -match '^## ') { break }
        if ($inEvidence -and ($line -notmatch '^```') -and ($line.Trim().Length -gt 0)) {
            $evidenceCount++
        }
    }
    if ($evidenceCount -lt 1) {
        [Console]::Error.WriteLine("[aidd gate] ERROR: $FilePath ($Label) has empty '## Execution Evidence' output.")
        exit 1
    }
}

function Assert-ApprovedVerdict {
    param([string]$FilePath)
    $lines = Get-Content -Path $FilePath
    $inRv = $false
    $approved = $false
    foreach ($line in $lines) {
        if ($line -match '^## Review Verdict\s*$') { $inRv = $true; continue }
        if ($inRv -and $line -match '^## ') { break }
        if ($inRv -and $line -match '(?i)^- \*\*Verdict:\*\*\s*`?APPROVED`?\s*$') {
            $approved = $true
            break
        }
    }
    if (-not $approved) {
        [Console]::Error.WriteLine("[aidd gate] ERROR: $FilePath is DONE but lacks '- **Verdict:** APPROVED' under '## Review Verdict'.")
        exit 1
    }
}
